# Subsetting using `[[` for eemlist - we want this to return an eem

Subsetting using `[[` for eemlist - we want this to return an eem

## Usage

``` r
# S3 method for class 'eemlist'
eemlist[[i]]
```

## Arguments

- eemlist:

  the eemlist to subset

- i:

  the index for subsetting

## Value

an object of class `eem`
